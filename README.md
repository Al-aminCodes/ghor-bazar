
# 🛒 বাজার দর | BazarDor

### Your Everyday Market Price Tracker

**বাজার দর (BazarDor)** is a web application designed to help users explore everyday essential products and understand their market prices in Bangladesh. It provides a user-friendly interface for browsing products, sorting prices, and making informed shopping decisions.

## 🛠️ Technologies Used

- **Next.js** — Application framework and routing
- **React** — Building reusable UI components
- **TypeScript** — Type safety and maintainable code
- **Tailwind CSS** — Responsive styling
- **DaisyUI** — Prebuilt UI components
- **Better Auth** — User authentication
- **MongoDB** — Database integration
- **React Hot Toast** — Notifications and user feedback

## ✨ Key Features

1. **📈 Market Price Tracker**  
   Explore market prices for everyday essential products.

2. **🛍️ Category-Based Browsing**  
   Browse products through organized categories for easy navigation.

3. **↕️ Smart Price Sorting**  
   Sort products by default order, price from low to high, or price from high to low.

4. **🔎 Product Details and Price Insights**  
   Explore product information and available market price details.

5. **🔐 User Authentication**  
   Sign up, sign in, and access account-related features.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Required environment variables

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Al-aminCodes/ghor-bazar.git
```

**2. Navigate to the project directory**

```bash
cd ghor-bazar
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env.local` file and add the environment variables required by your project.

**5. Run the development server**

```bash
npm run dev
```

**6. Open the application**

Visit https://ghor-bazar03.vercel.app/

BazarDor aims to make everyday market price information easier to access and understand, helping people make informed shopping decisions in Bangladesh.
